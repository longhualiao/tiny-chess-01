A chess engine in 4 KB of Python: 0x88 board, negamax with alpha-beta, iterative deepening to a fixed 60,000-node budget, quiescence search, transposition table and killer moves. Local practice trial-0: 1 win, 3 draws, 2 losses (~1191 Elo vs the anchors).

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
